## 编写与核验原则

- 本课程课件的可考查条目按原有分类和枚举数量完整表达，不再用“了解某某”一句话替代所有条目。
- 把背景、特点、优点、缺点和具体处理步骤放进正文；勘误只用于真实术语错误、容易误导的技术简化或版本差异。
- 对标准与课件存在差异之处，正文区分教学模型和协议标准，不悄悄删去课件口径；教学用表述不被解释成适用于现代所有系统的绝对规律。
- 不在学生可见正文插入原课件页码、编辑依据或“2025 版新增”之类的说明。
- 新增 Vitest 逐章节条目覆盖测试，原有结构、知识点和协议语义测试继续保留。
