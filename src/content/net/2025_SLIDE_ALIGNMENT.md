## 二、已明确定位的课件差错与适用条件

| 源件页 | 课件原表述或易误解之处 | 网页处理 |
| --- | --- | --- |
| 数据通信B，第8页 | T1 “发送一帧需要125毫秒”，与193bit×8000帧/s=1.544Mb/s矛盾 | 纠为 **125μs**，并列E1：256bit×8000=2.048Mb/s |
| 第4章 PPP 相关页 | “Terminate-Reply”“不足1500字节填充” | 按 RFC1661 改为说明 Terminate-Ack、默认MRU及Padding可选，保留原文出处 |
| 第5章 LAN 相关页 | 100BASE-FX“2对光纤” | 纠为通常一对（两根）分别发送与接收 |
| 第5章 LAN，第113—115页 | 半双工千兆延长争用时隙易被误认为以太网最短MAC帧512字节 | 分清 **4096bit争用时间** 与 **64字节MAC最小合法帧** |
| 第6章网络层-2，第6页 | ICMP Timestamp“从1900-01-01起的秒数” | RFC792：通常为 **UTC午夜起的毫秒数**，不是NTP纪元时间 |
| 第6章网络层-2，第30页 | “Bellman-Ford（或Ford-Fulkerson）” | RIP依据Bellman–Ford距离向量；Ford–Fulkerson是最大流算法 |
| 第7章传输层，第13页 | IGMP列入使用UDP的应用层协议 | **IGMP直接封装在IPv4中，Protocol=2**，UDP为17 |
| 第8章应用层，第32页 | FTP数据连接旁标“20” | 说明为经典主动模式；被动模式不要求服务器数据端口20 |
| 第8章应用层，第89页 | XHTML 将取代 HTML | 标明是历史时期的技术预测，不作为现行标准结论 |
| 第8章应用层，第102页 | 旧分类目录网站列举 | 视作历史例子，不表示服务仍正常运营 |

## 三、网页接入与自动回归边界

- 网站保留了旧版稳定的课后题号、知识点锚点以及旧稿中的电子邮件、HTTP/3拓展；新增 FTP 章节使用 `sec-ch8-ftp*`，补充 HTTP 小节使用 `sec-ch8-http-h6/h7`，因此不会占用已有锚点。
- `src/__tests__/net-content.test.ts` 检查八章结构（含第8章新节）、新知识点及对应页面锚点、关键勘误与数值。
- 代码级别存在性校验与原文内容对照，不等于自动证明每个 PPT 图示的所有细节、网页小屏视觉效果及学习进度交互完全正确；这些需要实际浏览器或 CI 执行。
- 2025 原始课件及引用资料的文件名已在仓库目录公开，**不需要上传或公开个人 Google Drive 分享地址及文件 ID**。
